→ UR10e; первые сравнения выполняются в MuJoCo. Этот список описывает
план экспериментов, а не уже подтверждённые улучшения.

Исходный результат: session `27daacc0ad084015b4bb409853ec7fda`, recorded input
×1, scale 0.25, position following, 50 Гц. По 255 active accepted samples:
средняя ошибка TCP 26.70 мм, RMSE 31.03 мм, p95 58.55 мм, max 62.79 мм.
Это слежение за уже отфильтрованной целью, не абсолютная точность кисти.
Методика: [online review](2026-10-19-online-review.md).

## 2. Причинное сглаживание: дрожание ↔ задержка

- [ ] Записать неподвижную кисть, медленное движение, быстрое движение,
  смены направления и частичные перекрытия.
- [x] Сравнить сочетания One Euro `min_cutoff` и `beta` при неизменном IK.
  Текущая отправная точка: 2 Hz / 0.5, derivative cutoff 1 Hz.
- [ ] Оценить дрожание на неподвижных участках и программное запаздывание
  фильтра относительно входных оценок; последнее не является абсолютной
  camera-to-actuator latency или ground-truth accuracy.
- [x] Сравнивать движение человека, filtered target и measured TCP совместно:
  замедление цели не выдавать за повышение точности всей системы.

Сравнение фильтров выполнено отдельно от IK на одинаковой pre-filter geometry,
baseline воспроизводится точно. На двух записях есть lag proxy, на synthetic
известной траектории — moving/stationary RMSE. Новая запись неподвижной кисти
с настоящих камер ещё нужна; synthetic noise её не заменяет.

- [ ] Измерить вариации длин костей, reprojection residual, дрожание кончиков,

- [ ] Отдельно оценить эффект на pinch/orientation и на будущую гуманоидную

Первый fixed-bone prototype использует десять начальных валидных кадров и
исследован на двух записях. Найдены смещение pinch и отбраковки; в live он не
включён. Продолжение: [расширенный эксперимент](2026-10-19-causal-hand-dataset.md)

суставами реализован отдельно от штатного live. Проверены все 10 доступных
эпизодов × 3 perception passes и пять synthetic сценариев × 3 seed.
Reprojection, pinch correction, CV геометрии и стоимость решения измерены;
ориентация и настоящее stationary jitter ещё требуют отдельной оценки.
Суставные пределы и thumb-модель приближённые. Восстановление скрытого
движущегося пальца даёт около 28.9 мм synthetic RMSE — для управления
гуманоидной рукой это пока не готовое решение.

## 4. Качество наблюдений и восстановление после потерь

- [x] Использовать согласованность камер, residual и геометрию лучей для
  управления весом измерения/силой фильтрации; handedness score не принимать
  за уверенность каждой 3-D точки.
- [x] Пересоздавать опору ориентации после длительной потери по нескольким
  свежим согласованным наблюдениям; не застревать на старом rotation gate.
- [x] Проверить короткие/долгие пропуски, большие повороты, вырожденную ладонь,
  повторные кадры и возврат кисти в кадр.
- [x] Сохранить ручной rebind после потери: восстановление оценки само по
  себе не возобновляет движение физического робота.

Quality-power weighting реализован как эксперимент и оставлен выключенным:
в текущем сравнении добавлял задержку. Orientation recovery — opt-in,
подтверждение по трём свежим кадрам. Проверки потерь/поворотов выполнены без
hardware; настоящее 6-D следование ещё предстоит проверить.

После запроса пользователя гипотеза quality weighting остаётся **открытой**:
двух коротких записей недостаточно для общего вывода. Расширенное сравнение
на всех доступных эпизодах и constrained hand fit с весами теперь завершено.
Геометрические оценки почти все высокие, точек с quality <0.5 нет; это
не полноценный тест плохой видимости. Информативные веса помогают на synthetic,
переставленные могут вредить. Нужна отдельная выборка с перекрытиями и
независимой проверкой ошибок. Данные и ограничения — в расширенном отчёте.
