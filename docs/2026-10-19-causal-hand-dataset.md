# Причинная модель кисти и веса качества: расширенный эксперимент

2026-10-19. Реализован и проверен экспериментальный `CausalHandFitter`:
фиксированная форма ладони, постоянные длины фаланг, ограниченные углы
суставов и опциональные веса качества. Общая гипотеза о пользе качества
**остаётся открытой**. У модели есть измеренные ограничения; в штатный live
контроллер она не включена.

## Реализация

Используется существующий CapsuleHand: свободное положение/ориентация кисти
и 20 суставных координат пальцев, всего 26 степеней свободы. Первые десять
полных валидных наблюдений причинно задают медианные длины фаланг и позиции
корней пальцев в системе ладони. Эти параметры затем заморожены. Нейтральные
оси пальцев привязаны к ладони, а не к сгибанию в первом кадре. Упрощённая
модель большого пальца и штатные пределы суставов — модельные допущения,
не индивидуально проверенная биомеханика.

Каждый новый кадр решается отдельно: робастная ошибка модельных XYZ против
измеренных XYZ, небольшой приоритет предыдущих углов, жёсткие суставные
пределы. Вес ошибки — `quality ** power`, power 0 / 0.5 / 1; для фильтрации
сравнивается отдельное применение quality. Максимум 20 вычислений функции.
Нет пакетного trajectory fit, доступа к будущим кадрам или depth-cloud fit.
Старт решения использует текущую измеренную ладонь и последние принятые
углы; после потери опора углов сбрасывается, геометрия сохраняется.

При пропуске наблюдаемых wrist/thumb-tip/index-tip управляющий результат
отклоняется. Остальные достроенные точки помечены `inferred`, а не `observed`.
Коррекция более 30 мм отклоняется, но конечные точки такого решения остаются
в диагностических сравнениях, чтобы не исключать неудобные примеры.
`accepted` отражает эти геометрические проверки; `converged` отдельно
показывает успешное завершение оптимизатора. Бюджет может закончиться раньше.

API и код: `viki/perception/live_hand_fit.py`, DTO в `viki/contracts.py`.
Эксперимент пока не меняет цели `LiveSession`, IK или физического UR.

## Протокол

- Все 10 доступных эпизодов `data/datasets/40mm-pnp`, полная длительность
  каждого, по три независимых запуска causal perception: **30/30 завершены,
  ошибок запуска нет**. 2549 результатов, 2092 с валидной позицией.
- Записанный источник проигрывается ×1, perception 15 Гц, latest-only.
  Это причинно обработанная запись, не новая съёмка живыми камерами.
  При исходных примерно 30 Гц не каждый нативный кадр поступает в inference.
- До обработки зафиксированы три train-эпизода: `11-00-24`, `11-12-44`,
  `11-15-00` от 2026-10-06. Семь других эпизодов — held-out; параметры модели
  по ним не подбирались. Начальная пользовательская калибровка в каждом
  эпизоде всё равно выполняется по его первым доступным полным кадрам.
- Для каждого прохода исходные XYZ, маски, quality и 2-D evidence заморожены;
  все 11 вариантов получают одинаковую последовательность. Хеши сохранены.
  Условие исходной валидности берётся из фиксированного baseline estimator.
- Основное парное сравнение: **1720 полных общих кадров**, после калибровки
  всех articulated-вариантов, включая конечные отклонённые решения. Старый
  fixed-bone prototype имеет дополнительные пропуски из-за своего cap;
  его результаты на оставшихся кадрах не являются строго парными с остальными.
- Сначала усредняются три прохода внутри эпизода, затем эпизоды получают
  одинаковый вес. Повторные inference passes не являются 30 независимыми
  человеческими демонстрациями. Это один набор одного стенда/участника.
- У реальных записей нет ground truth кисти. Reprojection — согласованность
  с теми же 2-D наблюдениями; lag — временное совмещение с сырыми оценками,
  не аппаратная latency. Длины костей и жёсткость ладони фиксированы по
  построению, нулевой CV сам по себе не доказывает точность.

## Реальные записи: семь held-out эпизодов

| Вариант | Среднее смещение pinch от raw, мм | Reprojection, мрад | Lag proxy, мс |
|---|---:|---:|---:|
| Raw | 0 | 4.131 | 0 |
| One Euro beta 0.5 | 14.266 | 22.840 | 70.5 |
| One Euro beta 30 | 3.702 | 7.788 | 15.0 |
| One Euro beta 30, quality power 1 | 5.324 | 9.647 | 22.4 |
| Модель по raw, равные веса | 5.036 | 7.909 | 6.0 |
| Модель по raw, quality power 1 | 5.051 | 7.873 | 6.2 |
| One Euro beta 30 → модель, равные веса | 7.043 | 10.313 | 20.5 |
| One Euro beta 30 → модель, quality power 1 | 7.067 | 10.281 | 20.7 |

Взвешивание внутри модели даёт небольшой выигрыш по reprojection: −0.0365
мрад относительно равных весов на held-out. Интервал bootstrap по семи
эпизодам: [−0.0482; −0.0247] мрад; это описательная оценка внутри этого
набора, не доказательство улучшения абсолютной точности. Вариант с моделью
хуже raw по reprojection, потому что навязывает геометрические ограничения.
Прямое усиление сглаживания через quality увеличивает lag proxy.

На всех эпизодах CV длин фаланг raw 8.25%, расстояний между корнями ладони
6.79%; у модели оба практически нулевые по построению. Вариант model/raw/q1
имеет 1820 конечных решений: 1814 проходят correction/geometry gates,
6 отклонены по коррекции. 1786 решений достигли критерия сходимости;
37 кадров достигли лимита nfev=20 (эти группы могут пересекаться).
Среднее по прогонам p95 времени model/raw/q1 — 7.27 мс, включая калибровку
в соответствующем прогоне. Это время постобработки, не всего perception
и не гарантия частоты при работе с аппаратурой.

**Важное ограничение quality:** среди 51 243 принятых наблюдений точек
нет ни одной с quality в [0.1; 0.5), 3977 в [0.5; 0.8), 47 266 ≥0.8.
Используется геометрический score: согласованность лучей, reprojection и
доля согласованных камер. Это не вероятность правильности и не уверенность
видимости каждой точки. MediaPipe handedness score не используется как
landmark confidence. Набор почти не проверяет поведение при низком quality;
по нему нельзя отклонить гипотезу о пользе настоящей оценки видимости.

## Синтетический контроль: известное истинное положение

Пять сценариев × три seed, по 100 кадров. Общий чистый causal calibration
prefix; затем движение, шум и отдельно частичная потеря/изменение ладони.
Здесь ground truth известен, но геометрия близка к модели эксперимента.
Сценарий изменения ладони добавлен как проверка ошибки модельных допущений.
Ни один сценарий не заменяет эксперимента на настоящих перекрытиях.

RMSE управляющей точки, мм, среднее трёх seed на общих кадрах:

| Сценарий | Raw | One Euro beta 30 | OE + quality 0.5 | Модель, равные веса | Модель + quality 1 |
|---|---:|---:|---:|---:|---:|
| Одинаковый шум всех точек | 2.37 | 3.08 | 3.41 | 1.78 | 1.78 |
| Низкое quality действительно означает большой шум | 9.60 | 7.75 | 5.46 | 7.14 | 5.80 |
| Quality случайно переставлено между точками | 10.46 | 8.63 | 8.46 | 7.28 | 7.97 |
| Скрыт движущийся безымянный палец | 2.34 | 3.15 | 3.52 | 1.75 | 1.75 |
| Ладонь меняет форму вне модели | 2.37 | 3.08 | 3.41 | 1.78 | 1.78 |

В случае информативного quality модель получает выигрыш 7.14 → 5.80 мм
по управляющей точке; если веса неинформативны — ухудшение 7.28 → 7.97 мм.
Это поддерживает необходимость проверить информативность самого score,
а не просто выбрать побольше сглаживания.

**Достраивание скрытых пальцев не решено:** RMSE скрытых точек безымянного
пальца около **28.9 мм**. Pinch при этом почти не меняется, потому что этот
палец в его определении не участвует. Хорошая управляющая точка не означает
правильную анимацию всех пальцев. При изменении формы ладони all-landmark
RMSE модели растёт 2.12 → 2.45 мм, хотя pinch почти прежний. Для будущей
гуманоидной руки нужна отдельная оценка суставов и невидимых пальцев.

## Вывод и следующий эксперимент

Модель реализована и многократно проверена как эксперимент. Она обеспечивает
геометрическую согласованность, но смещает наблюдаемые точки. Автоматически
включать её в физическое управление по этим результатам оснований нет.
Общая гипотеза quality weighting не отклоняется: контролируемый пример
показывает пользу информативных весов, а реальный набор почти весь состоит
из высоких оценок геометрического качества.

Далее нужны записи с контролируемыми перекрытиями, неподвижной кистью и
независимая проверка видимости/ошибки (разметка части кадров или удержанная
камера). Затем калибровать веса по фактическим ошибкам; отдельно проверить
thumb opposition, допустимую подвижность ладони, ориентацию и скрытые пальцы.
До этого experimental fit доступен для сравнения, defaults не меняются.

## Артефакты и повторение

Числовые агрегаты без калибровки стенда:
[results JSON](2026-10-19-causal-hand-dataset-results.json).
Локальные capture/evidence и traces лежат в игнорируемом Git каталоге
`data/live_anatomy_experiments/`: `2026-10-19-captures`,
`2026-10-19-model-comparison-v3`, `2026-10-19-synthetic-v2`.
Промежуточные comparison/v2 не являются итоговым протоколом; v3 добавляет
raw baseline и сравнивает модели на общих кадрах независимо от старого cap.

Команды из корня репозитория (все расчёты внутри Docker):

```bash
docker compose run --rm --entrypoint python live scripts/capture_live_dataset.py data/datasets/40mm-pnp --out data/live_anatomy_experiments/NEW-captures --repeats 3 --train-episodes 2026-10-06_11-00-24 2026-10-06_11-12-44 2026-10-06_11-15-00
docker compose run --rm --entrypoint python live scripts/benchmark_live_anatomy_dataset.py data/live_anatomy_experiments/NEW-captures --out data/live_anatomy_experiments/NEW-comparison
docker compose run --rm --entrypoint python live scripts/benchmark_live_anatomy_synthetic.py --out data/live_anatomy_experiments/NEW-synthetic
docker compose run --rm -v "$PWD/docs:/app/docs" --entrypoint python live scripts/summarize_live_anatomy.py data/live_anatomy_experiments/NEW-comparison data/live_anatomy_experiments/NEW-synthetic --out docs/NEW-results.json
docker compose run --rm live-test
```

Проверки: 570 passed, 7 skipped; отдельно проверены аналитический Jacobian
по конечным разностям при ненулевом SE(3) приращении, причинная заморозка
калибровки, пропуски control/noncontrol и отсутствие generic fallback при
неполной калибровке. Настоящие камеры и физический UR не запускались.
